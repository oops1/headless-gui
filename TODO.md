# TODO — роадмап headless-gui

Гэп-анализ против популярных Go-тулкитов (Fyne, Gio, Wails) на 2026-07.
Рендер, текст (шейпинг), HiDPI, AA, Wayland и тестовая инфраструктура уже
на уровне или впереди; разрывы — в «обвязке приложения».

**Инвариант всех работ: headless-контракт неприкосновенен.**
`engine.Frames()` (дельта-тайлы), `SendMouse*/SendKeyEvent`, логические
координаты и zero-CGO не ломаются ни одной фичей из этого списка.

## 3. Стратегические (большие ставки)

- [x] **Конвейер отрисовки для потребителя** — сделано 2026-08-28 (v3.15.0)
      по `ENGINE_PIPELINE_PLAN.md`. Пропуск поддеревьев вне изменившейся
      области (`SetSubtreeCulling`, по умолчанию включён) и объявленный
      контракт отрисовки: `Draw` больше не гарантирован каждый кадр.
      Классификация содержимого тайлов (`Frame.Regions`: сплошной цвет с его
      значением, текст, изображение, честное «не знаю») — потребителю больше
      не нужно восстанавливать это вторым проходом кодека. Объявление
      переноса содержимого (`widget.NotifyMove`, `Frame.Moves`): окно,
      которое переехало, копируется у потребителя вместо пересылки.
      Внешний темп кадров (`SetPacing`, `RequestFrame`, `SetFrameSink`) —
      для привязки к вертикальной синхронизации и чтобы потребитель мог
      менять сцену и готовить кадр в одной горутине. Порядок каналов буфера
      и отрисовка в чужую память (`SetPixelFormat`, `SetSurface`).
      Числа до и после — в `docs/AI_AGENT_REFERENCE.md`, раздел
      «Measured cost of a frame».


- [x] **Темы как данные и системная панель задач** — сделано 2026-08-28
      (v3.14.0). Пакет `theme/`: профиль темы (цвета, метрики, признаки,
      шрифты, иконки, анимации, презентеры, стили компонентов) с
      наследованием, загрузкой из JSON и сменой на лету; состояния —
      битовая маска, сводимая к главному (шесть записей на компонент вместо
      тридцати двух); `GetStyle` не выделяет памяти. Готовые профили
      Windows 11 / Windows 10 / Windows 2000 / macOS со светлыми и тёмными
      разновидностями — тёмная объявляет три-четыре токена, остальное берёт
      у родителя. Старые пресеты `widget.Theme` продолжают работать через
      двусторонний мост (`widget.ProfileFromTheme` / `widget.Materialize`),
      поэтому это v3.14.0, а не v4.
      Пакет `desktop/`: панель задач со слотами, кнопка «Пуск», область
      приложений, полоса окон, контейнер трея с переполнением, значки сети /
      звука / питания, часы (тик раз в секунду и только при смене
      отображаемой строки), меню «Пуск», календарь, быстрые настройки, центр
      уведомлений. Данные системы приходят через интерфейсы потребителя;
      движок поставляет фейки. Тема вправе принести и свою отрисовку
      компонента — презентер: под macOS область приложений становится доком.
      Движок: размытие подложки (акрил/слюда), мягкие тени по `Elevation`,
      клип по скруглённому контуру, набор встроенных иконок, damage-области
      списком вместо одного объединения.
      Демонстрация: `go run ./cmd/desktopdemo`.
      Радиальные градиенты в стиле темы (подсветка под значком дока) и тема
      на поддерево (`widget.ThemeScope`: окно гостя в его теме рядом со своим
      интерфейсом, глобальная смена темы область не трогает).
